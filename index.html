Midnight Restaurant · art for ChatGPT

まよなか屋 art pack36 pictures, one chat, one style

Everything the game draws, ready to send to ChatGPT. Each picture has a prompt to copy and a sketch from the current game that shows the shape and the layout.

How to make them

  1. Start a new ChatGPT chat. Attach your target picture, paste the style message below, and send it.
  2. For each picture: open its sketch, save it, and attach it in the chat. Then tap Copy prompt, paste and send.
  3. Save what ChatGPT makes. On iPhone, Save to Files keeps the see-through background.
  4. Upload them to github.com/LACHENDE/midnight-restaurant-art with Add file → Upload files. Any file names are fine.
  5. Tell Claude they're up, and they go into the game.
If a picture drifts from your style, reply: “Match the style of my first picture more closely.” A white or black background instead of a see-through one is fine. Claude can cut it out. No Add file button on your phone? In Safari tap aA → Request Desktop Website.

Style message: send this first

Attach your target picture to this message. It sets the look for all 36 pictures.

I'm making a cozy two-player ramen-stall game called Midnight Restaurant, and I'll ask you for 36 game pictures, one per message. The picture attached here is my style target: match it in every picture. Style: chunky, rounded, toy-like shapes, like soft vinyl toys or smooth clay, with simple forms and not too many details. Warm, soft light from orange paper lanterns, gentle shading and soft highlights, a cozy rainy night in Japan. Colours: warm wood browns, lantern orange, noren red, deep navy night, cream, and a little mint green for small accents only. Camera: from the front and a little above, like a side-view game, so round things such as bowls, pots and cups show an oval top. Rules for every picture: - No text, letters, kana, numbers or logos anywhere, and no watermark. - For an object or a character: only that one thing, centred, whole, with space around it, on a transparent background. No table, no floor, no cast shadow. - For a scene: fill the whole picture, with no people in it. - Keep the same style, lighting and level of detail in every picture of this chat. With each request I'll attach a rough sketch from the current version of the game. Use it only for the shape, the angle and where things go, never for the style. Reply "ready" and wait for my first request.
