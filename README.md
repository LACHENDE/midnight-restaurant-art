# まよなか屋 Midnight Restaurant: art drop-off

Upload the ChatGPT pictures for [Midnight Restaurant](https://github.com/LACHENDE/midnight-restaurant) here, then tell Claude. Any file names are fine; Claude sorts them out and puts them into the game.

**To upload from a phone:** on this page tap **Add file → Upload files** and pick the pictures. If you don't see Add file, switch Safari to the desktop site (aA → Request Desktop Website).

**The pack:** the phone page (https://claude.ai/artifact/PGd8nTwc6pNsk8bKE6KRvo) has a Copy button for every prompt and each sketch. The same prompts are in [prompts.md](prompts.md), and the sketches are in [ref/](ref/).

- 36 pictures: 2 scenes, 5 guests (sitting and calling for staff), 14 kitchen things, 6 counter things, 3 decorations and the menu picture.
- Make them in one ChatGPT chat so they share a style. Send the style message first, with your target picture attached.
- A white or black background instead of a see-through one is fine: Claude can cut it out.
